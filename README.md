# Social Media Sentiment Analyzer

A Python web app that analyzes the sentiment of social media comments.

## What it does
- Detects if a comment is Positive, Negative or Neutral
- Shows a polarity score from -1 to +1
- Visual progress bar showing sentiment strength
- Color coded results
